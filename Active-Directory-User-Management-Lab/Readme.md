# Active Directory User Management Lab

## About This Lab
In this lab I practiced managing users and groups in Active Directory using Windows Server 2022.

I created organizational units, users, and security groups to understand how companies manage permissions and authentication in enterprise environments.

## What I Did
- Created Organizational Units (OU)
- Created Active Directory users
- Created security groups
- Added users into groups
- Explored Domain Admins group
- Learned about least privilege and access control

## Organizational Units
- IT
- HR
- SOC

## Users Created

## What I Learned
- Basics of Active Directory administration
- User and group management
- Enterprise access control
- Least privilege concept
- Privileged account monitoring

- Windows Server 2022
- Active Directory Users and Computers
- VirtualBox
