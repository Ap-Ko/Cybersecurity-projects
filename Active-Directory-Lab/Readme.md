# Active Directory Lab

## Objective
Built a Windows Server Active Directory lab environment by installing Active Directory Domain Services (AD DS) and configuring a Domain Controller inside Oracle VirtualBox.

## Technologies Used
- Oracle VirtualBox
- Windows Server 2022
- Active Directory Domain Services (AD DS)


## Skills Learned
- Windows Server administration
- Active Directory fundamentals
- Domain Controller setup
- User and group management
- Basic Windows administration


## Tasks Performed
- Installed Windows Server 2022 in VirtualBox
- Configured NAT Network
- Installed Active Directory Domain Services
- Promoted server to Domain Controller
- Created custom domain environment
- Created Active Directory user (Ap Ko)
- Created security group (SOC-Team
- Added user (Ap Ko) into groups


## Active Directory Concepts Learned
- Domain Controller
- Authentication
- Users and Groups
- Organizational management
- Enterprise access control

## Outcome
Successfully deployed an Active Directory lab environment and practiced enterprise-style user and group management tasks relevant to SOC Analyst and IT Administration roles.
